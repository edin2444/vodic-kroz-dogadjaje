# Bakson: Vodič Kroz događaje
Projekat, ukratko, nudi mogućnost praćenja događaja, koncerata, predavanja i radionica koja se dešavaju u Beogradu.

# Instrukcije za pokretanje
Nakon preuzimanja i raspakivanja projekta, dovoljno je otvoriti index.html fajl u pregledaču.

# Korišćene tehnologije
Korišćene tehnologije (u dosadašnjem radu) su HTML, CSS, JavaScript i Bootstrap.

# Implementirane funkcionalnosti
Implementiran je vizuelni prikaz događaja i filter za iste. Kada korisnik odabere tip događaja, korisniku se prikažu samo događaji iz odabrane kategorije. Klikom na opciju "Svi događaji", prikaz se vraća na početno stanje (ponovo se prikazuju svih šest događaja).

# Približno utrošeno vreme
7 sati i 30 minuta efektivnog rada.

# Najveća poteškoća
Definitivno filtriranje. Koristio sam pomoć AI alata za isti.

# Poznati problemi i nezavršene stavke
Trenutno nema nezavršenih stavki. Sve je implementirano po trenutnim zahtevima.

# Korišćenje AI alata
Koristio sam AI alat za otklanjanje grešaka prilikom implementacije navigacionog menija (pogrešna verzija Bootstap-a je bila u pitanju) i kao ispiraciju za sadržaj stranice (u smislu događaja i njihovih opisa). Takođe, kao što sam već naveo, koristio sam ga kao pomoć za implementaciju filtera za događaje. Prilikom implementacije filtera, imao sam par problema koji su se ticali organizacije elemenata na strani i animacija koje su se ponavljale bez preke potrebe. Blagim izmenama koda i kasnijom proverom (otvaranjem veb strane), uspeo sam da rešim prethodno pomenute probleme.
